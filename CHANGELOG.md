## v2.1.0 - 2026-08-26
### Added
* Build-time generation of shell completions and man pages
### Fixed
* Guard against pathologically aggressive temporary file cleaners by using anonymous tempfiles

## v2.0.1 - 2026-08-10
### Fixed
* Improve performance when parsing window IDs

## v2.0.0 - 2026-08-10
### Changed
* Prefer current, then oldest session when workdir matches, and oldest window otherwise. Previously, this behavior was undefined and depended on the order in which services, windows, and sessions were returned.
### Fixed
* Use more reliable way to determine workdir equality
* Canonicalize workdir path before creating handle to fail early on invalid paths
